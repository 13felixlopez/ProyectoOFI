**CoffeeTec** es un sistema integral de seguimiento del proceso de secado del café, diseñado para optimizar y monitorear cada etapa del proceso, desde la recepción del café húmedo hasta su almacenamiento como pergamino seco. Con una combinación única de una **versión de escritorio** en C# Windows Forms, una **aplicación móvil** en Xamarin Forms, y una **API** en Node.js con Express, CoffeeTec ofrece una solución completa y escalable para la gestión del secado del café.

---

## 🎯 Objetivo

El objetivo principal de CoffeeTec es proporcionar un **seguimiento completo y medible** del proceso de secado del café, permitiendo a los usuarios tomar decisiones informadas y mejorar la eficiencia y calidad del producto final. Está diseñado para ser utilizado por **trabajadores, jefes de área y gerentes**, ofreciendo herramientas adaptadas a cada nivel de responsabilidad.

---

## ✨ Características principales

- **Registro detallado de lotes**: Ingresa información completa de cada lote, incluyendo peso, humedad, tipo de secado (natural, mecánico o mixto), y más.
- **Cálculos automáticos**: Calcula tiempos de secado, quintalaje total, y distribución por tipo de secado.
- **Resultados de catación y rendimiento**: Registra y analiza los resultados de catación y el rendimiento en pergamino seco.
- **Reportes en Excel**: Genera reportes automáticos en formato Excel con datos clave de cada proceso.
- **Versión móvil y de escritorio**: Dos aplicaciones que se complementan para ofrecer flexibilidad y acceso en tiempo real.
- **API eficiente**: Desarrollada en Node.js con Express, optimizada para reducir el consumo de internet en dispositivos móviles.

---

## 🛠️ Tecnologías utilizadas

- **Versión de escritorio**: C# Windows Forms
- **Versión móvil**: Xamarin Forms
- **Base de datos**: SQL Server
- **API**: Node.js con Express

## 🚀 Instalación y uso

### Requisitos previos
- **SQL Server**: Asegúrate de tener el puerto de SQL Server abierto para conexiones.
- **Node.js**: Para ejecutar la API en Express.
- **VPN**: Para conexiones fuera de la red local.

### Pasos para la instalación

Instala la versión de escritorio utilizando el archivo .exe incluido, que contiene .NET Framework integrado.

Configura la aplicación móvil en Xamarin Forms.
